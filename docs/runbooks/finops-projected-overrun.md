# FinOps projected-overrun

Owner: FinOps with Developer/SRE support. M14 PROVISIONAL, disabled by default.
Rule: `projected-overrun`. Daily UTC usage, one environment, native currency.

1. Open Settings → Observability & FinOps → FinOps. Check source freshness,
   issue time, eligible/missing days and quality before monetary interpretation.
2. Inspect protected cached history, M11 corrections/late rows and M12 immutable
   reconciliation generation. Later corrections create new evaluations; retain earlier
   forecasts. Check DIRECT/SHARED/UNALLOCATED controls, mapping and allocation coverage.
3. Check M13 AVAILABLE unit numerator, denominator, population, currency and freshness.
   Partial financial/denominator coverage means unknown, not savings or improvement.
4. Inspect robust baseline, absolute/relative floors, zero-MAD fallback and distinct-day
   persistence. Check forecast eligible-day arithmetic, LOW confidence, scenario range
   and walk-forward qualification. A scenario range is not a confidence interval.
5. Inspect numeric contributors and available release/config history as correlation
   only. Without authoritative evidence retain UNEXPLAINED. Shared pools are not
   individual-turn charges. Do not attribute a cause from model names or prompt text.
6. Group one source/environment/currency event. Source-quality degradation is the root
   and suppresses financial symptoms. Overlapping budgets are independent views, not
   additional spend. Repeated evaluations do not add persistence or notifications.

Safe diagnosis uses protected read-only APIs and reviewed source-controlled definitions.
No automatic routing, scaling, quota/provider changes, tools, commands or turn blocking.
Any external action requires existing governance and exact-operation AGENTS.md approval
with target, operational/security/cost impact, data risks and rollback. No channels or
cloud policies are deployed. Recovery requires a fresh complete validated generation;
disappearing data never resolves an anomaly. Budget changes create reviewed versions.
